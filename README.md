# Передайте за проезд

Кооперативный хаос в маршрутке на 1–4 игроков прямо в браузере.

Вы — пассажиры набитой «Газели». Деньги нужно передать по цепочке рук водителю в кассу, сдачу и чужие вещи (торт, огурцы, гуся, кактус) — назад, на галёрку. Водитель гоняет по ямам и тормозит, всё летает. Пустые места занимают боты: Баба Зина, Дед Толя, Студент Вася и Мужик Гена.

## Управление
- **Мышь** — рука
- **Зажать ЛКМ** — схватить, **отпустить** — бросить
- **Пробел / ПКМ** — наклониться к полу
- **1–5** — крикнуть («Передайте за проезд!», «СДАЧУ!!!»…)

## Как играть вместе
1. Один нажимает «Создать маршрутку» и скидывает друзьям ссылку (или 4-буквенный код).
2. Остальные открывают ссылку и жмут «Войти по коду».
3. Хост жмёт «Поехали!». Вкладку хоста лучше держать открытой — физика считается у него.

## Техника
- Чистый HTML + JS, без сборки. Физика — [Matter.js](https://brm.io/matter-js/).
- Мультиплеер — WebRTC через [Trystero](https://github.com/dmotz/trystero): игроки находят друг друга через публичные WebTorrent-трекеры, дальше связь напрямую. Своего сервера нет, всё бесплатно.
- Хост считает физику и шлёт снимки 30 раз в секунду, остальные шлют только положение руки.
