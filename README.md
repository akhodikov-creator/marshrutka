# Передайте за проезд

Кооперативный хаос в маршрутке на 1–4 игроков, от первого лица, прямо в браузере.

Вы — пассажиры набитой «Газели». Деньги нужно передать по цепочке рук водителю в кассу, сдачу и чужие вещи (торт, огурцы, гуся, кактус, ведро с карасями) — назад, на галёрку. Водитель гоняет по ямам, резко тормозит и закладывает повороты — всё летает по салону. Пустые места занимают боты: Баба Зина, Дед Толя, Студент Вася и Мужик Гена.

## Управление
- **Мышь** — смотреть; рука тянется туда, куда смотришь
- **Зажать ЛКМ** — схватить, **отпустить** — бросить
- **ПКМ** — швырнуть то, что в руке
- **Пробел** — наклониться (достать с пола)
- **1–5** — крикнуть («Передайте за проезд!», «СДАЧУ!!!»…)

## Как играть вместе
1. Один нажимает «Создать маршрутку» и скидывает друзьям ссылку (или 4-буквенный код).
2. Остальные открывают ссылку и жмут «Войти по коду».
3. Хост жмёт «Поехали!». Вкладку хоста не сворачивать — физика считается у него.

Есть и старая [2D-версия](2d/).

## Техника
- Чистый HTML + JS-модули, без сборки. 3D — [Three.js](https://threejs.org/), физика — [cannon-es](https://github.com/pmndrs/cannon-es).
- Мультиплеер — WebRTC через [Trystero](https://github.com/dmotz/trystero). Комната открывается сразу в трёх бесплатных сетях-«знакомцах» (MQTT, WebTorrent-трекеры, Nostr), какая первой соединит — через ту и играем. Своего сервера нет.
- Хост считает физику и шлёт снимки 30 раз в секунду, остальные шлют, куда смотрят и куда тянут руку.
